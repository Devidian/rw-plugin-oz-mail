# OZ Mail 0.4.0

- Mail now shows each attachment with an item image and amount; players can claim one attachment at a time.
- Cash on delivery is charged once before the first claim. Paid mail is retained instead of being returned on expiry.

The database migration adds the COD paid state without discarding existing mail. Keep the existing mail database when updating.

Requires Java 25 and the current Rising World PluginAPI.
