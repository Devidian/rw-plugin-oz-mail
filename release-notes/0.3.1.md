# OZ Mail 0.3.1

- Mail history now labels single-attachment claims, rejected claim payments, and return-mail events in German and English.
- Unrecognized future audit events show their event code so administrators can identify them.
- The plugin is built with Java 25 and the current PluginAPI 0.9.3.2 JAR.

Requires OZ Tools 0.27.0 and Rising World Unity with PluginAPI 0.9.3.2. Keep the existing mailbox database and world settings when upgrading.
